# Windows SSH 部署与排障参考

本文只提供方法和通用示例，不包含真实部署环境信息。

## 目标与凭证

从当前项目及本机 `~/.ssh/config` 确认 SSH 别名、用户、端口和密钥路径。只在授权范围内使用已有凭证。无需把私钥、密码、业务配置或本机目录加入仓库。

新主机先通过可信渠道核对 SSH 指纹。对于既有主机的指纹变化，不自动接受新指纹。`Permission denied`、超时、拒绝连接、名称解析失败和本地权限受限分别处理。

## 管理隧道

后台管理仅允许本机访问时，可以使用只监听本机的 SSH 隧道。以下主机与端口均为示例，实际执行前检查本地端口是否空闲：

```sh
ssh -N -T -o BatchMode=yes -o StrictHostKeyChecking=yes \
  -o ExitOnForwardFailure=yes -o ForwardAgent=no \
  -o ServerAliveInterval=15 -o ServerAliveCountMax=2 \
  -L 127.0.0.1:12346:127.0.0.1:12345 windows-server
```

示例中，本机 `http://127.0.0.1:12346` 转发到远端 loopback 的 12345 端口。端口冲突时选空闲端口，不终止不属于本次任务的进程。完成后关闭自己创建的隧道会话。

## 审查现有部署脚本

以下是从实际部署中提炼的检查点，是否适用取决于当前项目源码：

- 远端存在性检查必须使用三态结果。不能将 SSH 或权限错误当成“数据库不存在”，进而复制本地数据库和凭证。即使预检成功，部署入口本身也必须正确处理后续连接失败。
- 主机、端口、根目录、任务名的覆盖参数可能没有传遍全部步骤。检查末尾健康请求、防火墙地址、任务注册及数据目录是否仍使用旧常量。
- 一些部署器只在健康检查失败时恢复旧应用，不能恢复其他异常，也可能成功后删除临时备份。执行前保留独立、带时间戳的备份，并明确数据迁移是否可回滚。
- 创建配置时使用的新端口不一定覆盖已有配置。读取实际配置并核对监听，不把传入参数当成部署结果。
- 更新程序不应复制本机已有服务的数据目录到远端。加密供应商配置与其 master key 必须保持配套，首次迁移须在明确任务范围内。
- 创建计划任务、重设 ACL、重建防火墙规则都是实际变更。核对原设置和目标效果，不在普通更新中扩大网络开放范围。
- Windows 计划任务若使用 `Interactive` 登录类型，机器重启后可能需要该用户登录才能启动。任务存在与服务正在运行分别核验。
- 源码目录与实际运行副本分别检查。新增运行资源需进入上传清单；对相关文件比较 SHA-256，再核实进程正在运行新版本。

本 skill 不捆绑某个私有项目的安装器。读取目标项目已维护的部署脚本，修正本次有关的缺陷后使用，不凭空假设所有项目都有同一个部署命令。

## PowerShell 与命令长度

`scripts/probe.py` 将固定 PowerShell 脚本和经过单引号转义的参数编码为 UTF-16LE Base64，通过无本地 shell 的进程参数发送。编码不提供保密性，不能用来隐藏密码或令牌。

Windows 的命令解释器有命令长度限制。探测脚本发送前检查长度；较大的部署脚本应作为文件传输并验证内容后执行，不继续堆叠编码命令。不要为了执行某个脚本永久降低全局 PowerShell 执行策略。

## CodexRelay 专用检查边界

`--relay` 针对以下布局：指定根目录下存在 `app/package.json`、`data/config.json` 和 `data/relay.sqlite`；计划任务名称由参数提供；指定 loopback HTTP 端口的 `/healthz` 返回 `status: ok` 和 `service: codex-relay`。

探测只返回配置中的必要字段、版本、文件存在性、任务状态和健康状态。任务运行、配置端口匹配及健康接口通过不等于上游模型和客户端授权可用。

排查模型接入时可以依次核对：

1. `codexEnabled`、实际 `codexBin` 及服务用户的登录状态。
2. 模型目录与客户端 Key 对应的授权元数据。
3. 客户端模型配置中的思考档位是否为模型支持值，且不超过 Key 上限。
4. 获授权的最小模型请求与实际客户端调用。

PowerShell 的 `codex` 可能解析为 `.ps1`；若受执行策略限制，先查找 `.cmd` 或实际 `.exe`。原生客户端与中转客户端可能使用独立配置，不复制其他机器的登录令牌解决身份问题。CLI 参数以目标机 `--help` 为准。
